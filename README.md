# Dosimetria da Pena

App de estudo de Direito Penal: sistema trifásico, flashcards com exportação para o Anki, questões comentadas, bizus de memorização, artigos de lei, jurisprudência do STF e do STJ e um simulador de cálculo da pena.

- `index.html`: o app (arquivo único, funciona offline).
- `Anki_Dosimetria_da_Pena.txt`: os 90 flashcards prontos para importar no Anki (Arquivo → Importar).

Material de estudo, revisado em novembro de 2026. Confira sempre o texto atualizado da lei e os informativos dos tribunais.
